# Raptor 3

[Español](README.es.md) · **English**

**Version 1.1.0** · [Release notes](docs/release-notes-v1.1.0.md)

**MCP Radio Automation Software.** A desktop player for radio automation, written in Rust with a [Slint](https://slint.dev) user interface and a built-in **MCP server** so an AI assistant can operate it.

Raptor was born in 1997 (Raptor 1, Delphi on Windows 95) and continued as Raptor II until 2007. Raptor 3 is a complete rewrite.

## Features

- **Sequential playlist** with transitions between tracks: intro, outro, overlay window and smart crossfade based on loudness.
- **Volume leveling** by loudness (LUFS, EBU R128) and fader.
- **Effects board** organized in pages, with smart music ducking (*Separation* setting).
- **Time, temperature and humidity announcement (HTH)**: built from pre-recorded voice clips with weather data from Open-Meteo, played over a music bed.
- **Scheduled commercial breaks**, advertisers, orders, daily log and a monthly airplay record (CSV) with proof-of-broadcast certificates.
- **Catalog** with search, item types (Song, Edited song, Podcast, Commercial, Effect, Dry, HTH…), metadata updates from file tags or from the internet (MusicBrainz, Deezer and iTunes) and cover art in the details panel.
- **Track editor** with waveform, zoom and keyboard shortcuts.
- User interface in **Spanish and English**.
- **MCP server** (Streamable HTTP at `http://127.0.0.1:8765/mcp`): an AI can build the playlist, play, mix, adjust the controls, fire effects and schedule breaks.

## Downloads

Builds for Windows, Linux and macOS are available under [Releases](https://github.com/AnibalFlores/raptor3/releases). Each one includes the program, the PDF manual in English and in Spanish, and the licenses.

The Windows executable is not digitally signed, so SmartScreen may warn the first time you run it: choose *More info › Run anyway*.

### macOS (experimental)

`MCPRaptorPlayer-macos-universal.zip` contains *MCP Raptor Player.app*, a universal app for Apple Silicon and Intel Macs, macOS 11 or later. It has not been tested on a real Mac yet: audio, file dialogs and the interface may have problems. Reports are welcome.

1. Unzip the file and drag *MCP Raptor Player.app* to *Applications*.
2. The app is not notarized by Apple, so the first time macOS refuses to open it. Open it once, close the warning, and go to *System Settings › Privacy & Security*: at the bottom, choose *Open Anyway* and confirm. On macOS 14 or earlier, a right-click on the app › *Open* is enough.
3. Alternatively, in the Terminal:

```bash
xattr -dr com.apple.quarantine "/Applications/MCP Raptor Player.app"
```

## Building

Requires **Rust 1.88 or later** (2024 edition), installed with [rustup](https://rustup.rs).

### Windows

```bash
cargo build --release
```

The executable is written to `target/release/mcp-raptor-player.exe`. *Help › Manual* opens the PDF in the interface language (`Raptor_Manual_en.pdf` or `Raptor_Manual_es.pdf`); from the project folder it finds them in `docs/manual`, and to distribute the program, copy them next to the executable.

### macOS

Requires the Xcode command line tools (`xcode-select --install`). To build the universal `.app` and its `.zip` in `target/`:

```bash
sh recursos/macos/empaquetar.sh
```

### Linux (Ubuntu / Debian, also WSL2 with WSLg)

```bash
sudo apt install build-essential pkg-config libasound2-dev libfontconfig1-dev libgtk-3-dev libudev-dev libwayland-dev libx11-dev libxcb1-dev libxcb-render0-dev libxcb-shm0-dev libxkbcommon-dev libssl-dev
```

```bash
cargo build --release
```

```bash
recursos/linux/instalar.sh
```

The script installs the executable in `~/.local/bin`, plus the icon and the menu launcher, without root permissions. Audio goes through PulseAudio (or PipeWire with its PulseAudio layer).

## Tests

```bash
cargo test
```

Tests use temporary folders and never touch the user's data. Screenshots of every window at several resolutions are generated separately, in `target/capturas`:

```bash
cargo test capturas -- --ignored --test-threads=1
```

To try the program without touching your real data, set `RAPTOR_CARPETA_DE_DATOS` to a test folder. The MCP server port can be changed with `RAPTOR_MCP_PUERTO`.

## Manual

The manual is written in HTML (`docs/manual/Raptor_Manual_es.html` and `Raptor_Manual_en.html`) with screenshots generated by the tests. To update the screenshots and the PDFs in both languages:

```bash
cargo test capturas -- --ignored --test-threads=1
```

```bash
RAPTOR_CAPTURAS_IDIOMA=en cargo test capturas -- --ignored --test-threads=1
```

```bash
python herramientas/manual.py
```

The script copies the screenshots to `docs/manual/imagenes` and prints the PDFs with Chrome, Chromium or Edge.

## Translations

User interface texts are written in Spanish and translated through the catalog `lang/en/LC_MESSAGES/mcp-raptor-player.po`. The tool `herramientas/traducciones.py` lists untranslated texts (`--faltantes`) and adds translations to the catalog (`--agregar`). A test checks that the catalog is complete.

## HTH voice clips

The time, temperature and humidity voice clips are **not included in the repository**. They are generated with [ElevenLabs](https://elevenlabs.io) using your own API key:

```bash
python herramientas/generar_locuciones.py --simular
```

```bash
ELEVENLABS_API_KEY=... ELEVENLABS_VOICE_ID=... python herramientas/generar_locuciones.py
```

The key is read **only from the environment**: do not write it in the script or commit it. Then, in the program, choose the folder by right-clicking the **HTH** button.

## Security

The MCP server listens only on `127.0.0.1`, rejects requests coming from web pages and **has no password**: do not expose it to the internet.
